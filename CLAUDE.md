# For AI agents

If a person asked you to install Gildsite, read and follow `INSTALL-FOR-AI.md` in this folder.
Run only `./gildsite-install check`, `plan`, `dns`, `status`, `docker-help` and `ai` until the person agrees to the plan.
The AI API key is typed by the person with `./gildsite-install ai-key` in their own terminal: never in the chat.
